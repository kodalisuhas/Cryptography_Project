# Skill: Performance Analysis

## Purpose

Analyze performance characteristics of cryptographic implementations.

---

# Metrics

- Encryption time
- Decryption time
- Throughput
- Memory usage
- CPU utilization (if measured)

---

# Workflow

1. Review benchmark configuration.
2. Execute measurements.
3. Collect metrics.
4. Compare results.
5. Identify bottlenecks.
6. Recommend improvements.

---

# Output

Return:

- Benchmark summary
- Graph recommendations
- Performance observations
- Optimization opportunities

Never optimize without measurement.
