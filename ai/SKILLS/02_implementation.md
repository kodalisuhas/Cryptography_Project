# Skill: Implementation

## Purpose

Generate production-quality code for a single approved task.

Implementation begins only after the planning phase has been completed.

---

# When to Use

Use this skill when:

- The implementation plan has been approved.
- Interfaces are finalized.
- Requirements are clear.

Never implement without a clear specification.

---

# Required Inputs

Provide:

- Current task
- Relevant documentation
- API specification
- Existing source file
- Approved implementation plan

---

# Workflow

## Step 1

Review all provided context.

---

## Step 2

Verify:

- Function signatures
- Architecture
- Dependencies

---

## Step 3

Implement ONLY the requested functionality.

Do not modify unrelated code.

---

## Step 4

Add:

- Type hints
- Google docstrings
- Input validation
- Error handling

---

## Step 5

Self-review implementation before presenting it.

---

# Constraints

Never:

- Rename public interfaces.
- Change architecture.
- Add new dependencies without approval.
- Generate placeholder implementations.

---

# Output

Return:

- Requested implementation only.
- Brief explanation of important decisions.
- Any assumptions made.

---

# Success Criteria

Implementation:

✓ Correct

✓ Readable

✓ Maintainable

✓ Matches API

✓ Ready for review
