# Skill: Testing

## Purpose

Generate or review tests for completed implementations.

---

# Test Categories

- Normal cases
- Boundary cases
- Invalid input
- Edge cases
- Exception handling
- Performance (if applicable)

---

# Workflow

1. Understand implementation.
2. Identify expected behavior.
3. Create test cases.
4. Review coverage.
5. Identify missing tests.

---

# Output

Return:

- Test plan
- Test cases
- Coverage observations
