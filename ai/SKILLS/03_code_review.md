# Skill: Code Review

## Purpose

Review AI-generated or human-written code before it is committed.

The goal is to identify correctness issues, architecture violations, security concerns, maintainability problems, and improvement opportunities.

---

# Review Workflow

1. Verify requirements.
2. Verify architecture.
3. Verify API.
4. Verify code quality.
5. Verify security.
6. Verify error handling.
7. Verify documentation.
8. Suggest improvements.

---

# Output

Provide:

Critical Issues

Major Improvements

Minor Improvements

Strengths

Overall Verdict

---

Never rewrite the entire module unless requested.
